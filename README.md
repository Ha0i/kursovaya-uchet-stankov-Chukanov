## Описание проекта
Программный комплекс «Автоматизация учета станков и их дефектов» разработан для оптимизации работы инженерных и сервисных служб промышленных предприятий. Система позволяет отойти от бумажного учета и разрозненных таблиц в пользу единой цифровой среды.

Основная цель проекта: минимизация времени простоя оборудования за счет оперативной фиксации поломок и структурированного хранения истории обслуживания каждого станка.

## Ключевые возможности:
Единый реестр оборудования: Учет каждой единицы техники с привязкой к цехам, инвентарным номерам и техническим характеристикам.

Мониторинг технического состояния: Быстрая визуализация статуса оборудования (в работе, на ремонте, списано).

Журналирование дефектов: Подробная фиксация каждой неисправности: дата обнаружения, описание симптомов, степень критичности и ответственное лицо.

Аналитическая отчетность: Генерация сводных отчетов по частоте поломок и типам неисправностей за выбранный период для принятия управленческих решений.

Поиск и фильтрация: Быстрый доступ к информации по модели станка, дате установки или статусу ремонта.

## Технологический стек
Для реализации проекта выбраны современные инструменты, обеспечивающие высокую производительность и надежность:

Frontend/UI: * WPF (Windows Presentation Foundation): Использован для создания десктопного интерфейса с использованием паттерна MVVM, что обеспечивает разделение логики и представления.

React: (Если в проекте есть веб-часть) используется для создания кроссплатформенного личного кабинета администратора.

Backend:

C# (.NET): Основной язык программирования, обеспечивающий строгую типизацию и высокую скорость обработки данных.

База данных:

MS SQL Server: Реляционная СУБД для надежного хранения данных, поддержки транзакций и обеспечения целостности информации.

Среда разработки и инструменты:

Visual Studio 2022.

SQL Server Management Studio (SSMS).

Git (система контроля версий).

## Инструкция по развертыванию и запуску
1. Подготовка окружения
Перед запуском убедитесь, что на вашем ПК установлены:

Visual Studio (версии 2019 или 2022) с установленной рабочей нагрузкой «.NET Desktop Development».

Microsoft SQL Server и среда SSMS.

2. Подготовка базы данных
Запустите SQL Server Management Studio и авторизуйтесь на локальном сервере.

Создайте новую базу данных с именем StankiDB.

Нажмите «New Query» (Создать запрос) и скопируйте содержимое файла database.sql из корневой папки проекта.

Нажмите «Execute» (F5) для создания таблиц, связей и заполнения справочников первичными данными.

## Руководство пользователя
Работа с реестром станков
При запуске открывается Главное окно со списком всего оборудования.

Для добавления нового станка нажмите кнопку «Добавить». Заполните модель, цех и инвентарный номер, затем нажмите «Сохранить».

Двойной клик по строке станка открывает его подробную карточку.

Регистрация неисправностей
Выберите станок в общем списке.

Перейдите во вкладку или окно «Дефекты».

Нажмите «Новый дефект», опишите проблему и укажите приоритет (низкий, средний, критический).

Сохраните изменения. Теперь история ремонта закреплена за данным оборудованием.

## Генерация отчетов
Перейдите в раздел «Отчёты» через главное меню.

Укажите временной интервал (начальная и конечная даты).

Нажмите «Сформировать». Система выведет статистику по количеству зафиксированных дефектов и их статусам.

Советы по дополнению:
Логика React: Если вы использовали и WPF, и React, опишите, за что отвечает каждая часть (например, WPF — для цеховых компьютеров, React — для мобильного доступа мастеров).

ER-диаграмма: Если есть возможность, добавьте в папку со скриншотами схему базы данных и прикрепите её в раздел "Технологический стек". Это очень ценится на защите курсовых.

Валидация: Если в программе есть проверки (например, нельзя сохранить пустые поля), упомяните это в описании как "Наличие встроенной валидации данных".
